# Roadmap

Habits v0.1 is intentionally local and narrow: conventional history discovery,
deterministic parsing and ranking, an interactive picker, and opt-in Zsh Ctrl-R
setup.

Future work may improve transparent lexical ranking and cross-platform terminal
behavior. The current scope explicitly excludes CWD and exit-status capture,
shell hooks, automatic configuration writes, databases, fzf, models,
fine-tuning, cloud calls, macro creation or execution, background services, and
publishing.
